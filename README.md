# ghfs-image-rewriter
Violentmonkey script to replace missing image URLs from GHFS 

## USAGE

1. Install Violentmonkey in your browser: https://violentmonkey.github.io/ 
2. Open GHFS: https://gloomhaven.smigiel.us/v2 
3. Open Violentmonkey
4. Open dashboard (cog icon)
5. New (plus icon)
6. Install from URL
7. https://raw.githubusercontent.com/earlybard/ghfs-image-rewriter/refs/heads/main/image-rewriter.js
8. Reload GHFS
